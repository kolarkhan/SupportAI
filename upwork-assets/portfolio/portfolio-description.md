# Portfolio Short Description

*(For the Upwork portfolio project's summary/overview field — keep this under ~150 words.)*

---

SupportAI is a full-stack, multi-tenant AI customer support platform I built end-to-end: businesses upload their own documents, connect a website, or write FAQs, and an AI agent answers customer questions using only that knowledge — with a real retrieval-augmented generation (RAG) pipeline, not a generic chatbot wrapper.

When the AI isn't confident, or a customer explicitly asks for a human, the conversation automatically escalates: a support ticket is created, the team is notified, and the AI steps back until a human agent takes over. Everything is managed from a dashboard covering conversations, a knowledge base, agent configuration, tickets, team roles, and analytics.

Built with Next.js 15, TypeScript, MongoDB/Prisma, and a provider-agnostic AI layer (OpenAI, Anthropic Claude, or a zero-cost built-in mode for demos). Fully responsive, with production-minded details like workspace-scoped authorization, prompt-injection–safe retrieval, and rate limiting.
